Gambaran besar: ML adalah optimasi

Hampir semua model ML dilatih dengan pola yang sama:

  1. Model punya parameter θ (bobot dan bias), dikumpulkan dalam satu vektor.
  2. Fungsi loss L(θ) mengukur seberapa buruk prediksi model pada data latih.
  3. Pelatihan adalah mencari θ yang membuat L(θ) sekecil mungkin.
  4. Caranya: hitung gradien ∇L(θ), lalu geser θ sedikit ke arah −∇L(θ). Ulangi.

Langkah 4 butuh kalkulus. Seluruh modul ini membangun pemahaman untuk satu baris kode itu: theta -= lr * grad.

Vektor dan dot product

Vektor di ℝⁿ adalah daftar n bilangan, misalnya x = (x₁, …, xₙ). Satu baris data pasien di skripsimu (usia, tekanan darah, kolesterol, …) adalah satu vektor.

Definisi
  • Dot product: w · x = w₁x₁ + w₂x₂ + ⋯ + wₙxₙ.
  • Norma (panjang): ‖x‖ = √(x · x).
  • Cosine similarity: cos θ = (w · x) / (‖w‖ ‖x‖), bernilai antara −1 dan 1.

Dot product mengukur seberapa searah dua vektor. Satu neuron menghitung z = w · x + b: skor yang besar jika input searah dengan bobotnya. Satu layer berisi banyak neuron sekaligus, yaitu perkalian matriks z = Wx + b, dengan setiap baris W adalah bobot satu neuron.

import numpy as np
w = np.array([0.5, -1.0, 2.0])
x = np.array([1.0,  2.0, 0.5])
print(w @ x)                                         # 0.5 - 2 + 1 = -0.5
print(w @ x / (np.linalg.norm(w) * np.linalg.norm(x)))  # cosine similarity

Turunan: laju perubahan

Definisi
f′(x) = limh→0 ( f(x + h) − f(x) ) / h
Artinya: jika x digeser sedikit sebesar h, f berubah kira-kira sebesar f′(x) · h. Secara geometris, f′(x) adalah kemiringan garis singgung.

Tanda turunan memberi arah: f′(x) > 0 berarti f naik di sekitar x (geser ke kiri untuk mengecilkan f); f′(x) < 0 berarti f turun (geser ke kanan). Di titik minimum, f′(x) = 0.

Aturan dasar: (af + bg)′ = af′ + bg′ (linear), dan (fg)′ = f′g + fg′ (hasil kali).

Cek turunan dengan komputer Turunan apa pun bisa diperiksa secara numerik: (f(x + 1e-5) - f(x - 1e-5)) / 2e-5. Teknik gradient checking ini dipakai praktisi untuk menemukan bug di implementasi backpropagation.

Aturan rantai: inti backpropagation

Aturan rantai (chain rule) Jika y = f(u) dan u = g(x), maka dy/dx = (dy/du) · (du/dx).

Bayangkan roda gigi: jika u berubah 3 kali lebih cepat dari x, dan y berubah 2 kali lebih cepat dari u, maka y berubah 6 kali lebih cepat dari x. Neural network adalah tumpukan fungsi, L = loss(σ(W₂ σ(W₁x))), dan aturan rantai mengalikan laju perubahan setiap lapisan, dari belakang ke depan. Itulah backpropagation.

Contoh. Turunkan h(x) = (3x + 1)². Ambil u = 3x + 1, maka h = u². dh/du = 2u dan du/dx = 3, jadi h′(x) = 2(3x + 1) · 3 = 6(3x + 1).

Contoh sigmoid. σ(x) = (1 + e⁻ˣ)⁻¹. Dengan u = 1 + e⁻ˣ: σ′ = −u⁻² · (−e⁻ˣ) = e⁻ˣ / (1 + e⁻ˣ)², dan dengan sedikit aljabar ini sama dengan σ(x)(1 − σ(x)). Nilai maksimumnya 0.25 di x = 0. Akibatnya, setiap lapisan sigmoid mengecilkan gradien paling sedikit 4 kali, sehingga pada jaringan dalam gradien bisa "menghilang" (vanishing gradient). Itulah alasan ReLU lebih populer di jaringan modern.

Turunan parsial dan gradien

Loss bergantung pada banyak parameter sekaligus. Turunan parsial ∂f/∂x adalah turunan terhadap x dengan variabel lain dianggap konstanta. Contoh untuk f(x, y) = x²y + 3y: ∂f/∂x = 2xy dan ∂f/∂y = x² + 3.

Gradien
∇f(x, y) = ( ∂f/∂x , ∂f/∂y )
Gradien adalah vektor yang menunjuk ke arah kenaikan tercuram f, dan panjangnya adalah besar kemiringan itu. Maka −∇f menunjuk ke arah penurunan tercuram.

Mengapa tercuram? Untuk langkah kecil berarah u (vektor satuan), perubahan f kira-kira ∇f · u = ‖∇f‖ cos θ. Nilai ini paling besar saat θ = 0 (u searah ∇f) dan paling kecil saat θ = 180° (u berlawanan ∇f). Dot product dari bagian vektor muncul lagi di sini.

Gradient descent 3D

Aturan pembaruannya, dengan learning rate α:

θ ← θ − α ∇f(θ)

Permukaan di bawah adalah grafik f(x, y). Bola adalah posisi parameter saat ini, panah merah adalah −∇f (arah yang akan dituju), dan garis adalah jejak yang sudah dilalui. Kontur di lantai adalah garis-garis dengan nilai f sama; perhatikan bahwa gradien selalu tegak lurus kontur.

            Yang perlu diamati
            
Pada mangkuk f = x² + y², langkah gradient descent adalah x ← x − α·2x = (1 − 2α)x. Jadi:

            
    
              
  • 0 < α < 0.5: x mengecil tanpa berganti tanda (turun mulus).
    • 
              
  • 0.5 < α < 1: |1 − 2α| < 1 tetapi negatif, sehingga x berganti tanda setiap langkah (osilasi) sambil tetap mengecil.
    • 
              
  • α > 1: |1 − 2α| > 1, x membesar setiap langkah (divergen).
    • 
            

            
Analisis sesederhana ini adalah cikal bakal teori konvergensi optimizer yang akan kamu temui di kuliah ML.

          

        


        

          
Melatih satu neuron dengan tangan

          
Gabungkan semuanya. Satu neuron sigmoid untuk klasifikasi biner (misalnya sakit jantung atau tidak):

          
z = w · x + b     ŷ = σ(z)     L = −[ y ln ŷ + (1 − y) ln(1 − ŷ) ]

          
L adalah binary cross-entropy. Kita butuh ∂L/∂w dan ∂L/∂b. Dengan aturan rantai:

          
∂L/∂w = (∂L/∂ŷ) · (∂ŷ/∂z) · (∂z/∂w)

          
    
            
  • ∂L/∂ŷ = −y/ŷ + (1 − y)/(1 − ŷ) = (ŷ − y) / (ŷ(1 − ŷ))
    • 
            
  • ∂ŷ/∂z = σ′(z) = ŷ(1 − ŷ)
    • 
            
  • ∂z/∂w = x dan ∂z/∂b = 1
    • 
          

          
Faktor ŷ(1 − ŷ) saling meniadakan, sehingga hasilnya sangat sederhana:

          
∂L/∂w = (ŷ − y) x      ∂L/∂b = ŷ − y

          
Artinya: koreksi bobot sebanding dengan kesalahan prediksi (ŷ − y) dikali input. Kombinasi sigmoid dengan cross-entropy dipilih justru karena menghasilkan gradien serapi ini, dan itulah yang dihitung PyTorch saat kamu memanggil loss.backward().


import numpy as np
rng = np.random.default_rng(0)
X = rng.normal(size=(200, 2))
y = (X[:, 0] + 2 * X[:, 1] > 0).astype(float)       # label sintetis

w, b, lr = np.zeros(2), 0.0, 0.5
sigmoid = lambda z: 1 / (1 + np.exp(-z))
for epoch in range(200):
    y_hat = sigmoid(X @ w + b)
    grad_w = X.T @ (y_hat - y) / len(y)               # rata-rata (ŷ − y)x
    grad_b = np.mean(y_hat - y)
    w -= lr * grad_w
    b -= lr * grad_b

acc = np.mean((sigmoid(X @ w + b) > 0.5) == y)
print(w, b, acc)   # w searah (1, 2), akurasi mendekati 1.0

        


        

          
Regresi linear: gradient descent vs rumus tertutup

          
Untuk model ŷ = Xw dengan loss mean squared error L(w) = (1/n)‖Xw − y‖², gradiennya ∇L = (2/n) Xᵀ(Xw − y). Menyamakan gradien dengan nol memberi solusi tertutup w = (XᵀX)⁻¹Xᵀy, yang memakai aljabar linier (nilaimu B+). Gradient descent dipakai saat data terlalu besar untuk menghitung invers matriks.


X = np.c_[np.ones(100), rng.uniform(0, 10, 100)]  # kolom bias + satu fitur
y = 3 + 2 * X[:, 1] + rng.normal(0, 1, 100)

w_closed = np.linalg.solve(X.T @ X, X.T @ y)      # jangan pakai inv() langsung

w = np.zeros(2)
for _ in range(5000):
    w -= 0.01 * (2 / len(y)) * X.T @ (X @ w - y)

print(w_closed, w)   # keduanya mendekati [3, 2]

        


        

          
Kesalahan umum

          
    
            
  • Lupa tanda minus. θ + α∇f justru naik ke puncak.
    • 
            
  • Learning rate asal-asalan. Terlalu kecil membuat pelatihan sangat lambat, terlalu besar membuat loss meledak menjadi NaN.
    • 
            
  • Lupa aturan rantai pada fungsi dalam. Turunan (3x + 1)² bukan 2(3x + 1).
    • 
            
  • Menganggap gradient descent selalu menemukan minimum global. Pada permukaan dengan banyak lembah, hasilnya bergantung titik awal.
    • 
            
  • Tidak menormalkan fitur. Fitur dengan skala sangat berbeda menghasilkan lembah sempit seperti contoh kedua, sehingga konvergensi lambat. Inilah alasan StandardScaler dipakai sebelum melatih.
    • 
          

        


        

          
Latihan

          

            
Latihan 1 · Mudah

            
Hitung turunan: (a) f(x) = 4x³ − 2x + 7, (b) g(x) = e^{2x}, (c) h(x) = ln(x² + 1).

            
Lihat pembahasan

              
(a) 12x² − 2. (b) 2e^{2x} (aturan rantai dengan u = 2x). (c) 2x / (x² + 1) (aturan rantai dengan u = x² + 1).

            

          

          

            
Latihan 2 · Mudah

            
Hitung ∇f untuk f(x, y) = x² + 3xy + y³ di titik (1, 2). Ke arah mana sebaiknya bergerak untuk menurunkan f?

            
Lihat pembahasan

              
∂f/∂x = 2x + 3y = 8, ∂f/∂y = 3x + 3y² = 15. Jadi ∇f(1, 2) = (8, 15), dan arah turun tercuram adalah (−8, −15), dinormalkan menjadi kira-kira (−0.47, −0.88).

            

          

          

            
Latihan 3 · Sedang

            
Lakukan tiga langkah gradient descent dengan tangan pada f(x) = (x − 3)², mulai x = 0, α = 0.25.

            
Lihat pembahasan

              
f′(x) = 2(x − 3). Langkah: x ← x − 0.5(x − 3). x₁ = 0 + 1.5 = 1.5; x₂ = 1.5 + 0.75 = 2.25; x₃ = 2.25 + 0.375 = 2.625. Jarak ke minimum (3) berkurang setengah setiap langkah.

            

          

          

            
Latihan 4 · Sedang

            
Untuk f(x) = x² dengan langkah x ← (1 − 2α)x, learning rate berapa yang mencapai minimum dalam satu langkah? Uji di simulator.

            
Lihat pembahasan

              
α = 0.5, karena 1 − 2α = 0. Pada permukaan nyata yang tidak simetris sempurna, tidak ada satu α yang optimal untuk semua arah, seperti terlihat pada contoh lembah sempit.

            

          

          

            
Latihan 5 · Sedang

            
Tunjukkan bahwa σ′(x) = σ(x)(1 − σ(x)).

            
Lihat pembahasan

              
σ′(x) = e⁻ˣ / (1 + e⁻ˣ)². Tulis sebagai [1/(1 + e⁻ˣ)] · [e⁻ˣ/(1 + e⁻ˣ)]. Faktor pertama σ(x). Faktor kedua = (1 + e⁻ˣ − 1)/(1 + e⁻ˣ) = 1 − σ(x). ∎

            

          

          

            
Latihan 6 · Menantang

            
Untuk neuron dengan aktivasi sigmoid tetapi loss squared error L = (ŷ − y)², turunkan ∂L/∂w. Bandingkan dengan hasil cross-entropy. Mengapa cross-entropy lebih disukai?

            
Lihat pembahasan

              
∂L/∂w = 2(ŷ − y) · ŷ(1 − ŷ) · x. Faktor ŷ(1 − ŷ) tidak hilang. Ketika neuron sangat yakin tetapi salah (misalnya ŷ ≈ 0.999, y = 0), faktor itu hampir nol sehingga gradien hampir nol dan neuron hampir tidak belajar dari kesalahan terbesarnya. Dengan cross-entropy, gradien (ŷ − y)x tetap besar di situasi itu.

Ringkasan

          
    
            
  • Melatih model ML berarti meminimalkan loss terhadap parameter.
    • 
            
  • Dot product mengukur keselarasan dua vektor; satu layer adalah perkalian matriks.
    • 
            
  • Turunan memberi arah dan laju perubahan; aturan rantai menurunkan fungsi bertingkat dan menjadi dasar backpropagation.
    • 
            
  • Gradien menunjuk ke kenaikan tercuram; gradient descent melangkah ke −∇f dengan learning rate α.
    • 
            
  • α terlalu kecil lambat, terlalu besar berosilasi atau divergen; titik awal menentukan lembah yang dicapai.
    • 
            
  • Untuk sigmoid dengan cross-entropy, gradiennya sederhana: (ŷ − y)x.
